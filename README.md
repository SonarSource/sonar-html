# Code quality and security for HTML

This repository contains the SonarQube static analyzer for HTML. It includes the analyzer implementation, checks, and tests for developers maintaining HTML analysis.

To learn more about Sonar’s HTML analysis, visit the [Sonar website](https://www.sonarsource.com/knowledge/languages/html/).
