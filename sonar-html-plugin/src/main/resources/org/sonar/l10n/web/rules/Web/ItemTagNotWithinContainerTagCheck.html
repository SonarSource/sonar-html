Why is this an issue?

The <dt> and <dd> HTML elements specify terms and descriptions in a description list. They must be used inside a <dl> element, either directly or in a <div> group that is a direct child of the <dl>. Common uses for description lists are to implement a glossary or to display metadata.

The <li> HTML element is used to represent an item in a list. It must be contained in a parent element: an ordered list (<ol>), an unordered list (<ul>), or a menu (<menu>).

Using a <li>, <dt>, or <dd> item tag outside of the aforementioned parent elements does not follow the HTML specification.

<li>Apple</li>          <!-- Noncompliant -->
<li>Strawberry</li>     <!-- Noncompliant -->

<dt>Apple</dt>          <!-- Noncompliant -->
<dt>Strawberry</dt>     <!-- Noncompliant -->

<dd>A fruit</dd>        <!-- Noncompliant -->
<dd>A berry</dd>        <!-- Noncompliant -->

To fix this issue, enclose <li>, <dt>, and <dd> with their respective allowed parent tags.

<ul> <!-- or <ul> or <menu> -->
  <li>Apple</li>
  <li>Strawberry</li>
</ul>

<dl>
  <div>
    <dt>Apple</dt>
    <dd>A fruit</dd>
  </div>
  <div>
    <dt>Strawberry</dt>
    <dd>A berry</dd>
  </div>
</dl>
